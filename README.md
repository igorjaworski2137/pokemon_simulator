# Pokemon Simulator

Pokemon Simulator is a school project created as a fan-made game inspired by **Pokemon Fire Red**. This is the first completed project published on GitHub and was developed using **Godot Engine** with scripts written in **GDScript**.

The game focuses on strategy and Pokémon knowledge, offering an experience aimed at fans familiar with Pokémon types, matchups, and mechanics.

## About the Game

The objective of the game is to defeat all opponents by analyzing each leader and identifying the Pokémon types they use. Success depends on choosing the right strategy and understanding Pokémon strengths and weaknesses.

The gameplay is inspired by classic Pokémon battles and rewards players who know the Pokémon universe well.
